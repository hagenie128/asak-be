# 화면에서 백엔드 API 찾기

| 화면 ID | 화면 기능 | 연관 API | 백엔드 확인 포인트 |
| --- | --- | --- | --- |
| SCR-003 | Kiosk 메뉴 목록 | API-001, 002 | 카테고리·정렬·품절·빈 목록 |
| SCR-004 | Kiosk 메뉴 상세 | API-003, 004 | 옵션 정책·재료 제외·가격 재검증 |
| SCR-005 | 장바구니 | API-004, 005 | 서버 가격·품절 검증 후 주문 저장 |
| SCR-007/008/012 | 결제/완료/결제 오류 | API-014, 006 | 활성 수단·멱등성·승인/실패 상태 |
| SCR-009/010 | 실시간 주문/주문 관리 | API-021, 007, 022, 008, 024 | 목록·상세·상태 전이·취소/환불 |
| SCR-011 | 품절 관리 | API-009, 010 | 메뉴/재료/옵션 품절 영향 |
| SCR-016 | 메뉴 관리 | API-011, 023, 012, 013 | 메뉴/옵션 정책 저장 |
| SCR-018 | 결제수단 설정 | API-015, 016 | Kiosk 노출과 같은 설정 원본 |
| SCR-019~021 | 매출 | API-017, 018, 019 | 매출 뷰·취소/환불·기간 집계 |
| SCR-022 | 대시보드 | API-020 | KPI·대기 주문 수 |
| SCR-023/024 | 영수증/멤버십 | 없음 | 현재 보류 범위 |

화면 ID는 API 구현의 출발점이 아니라 요청자가 기대하는 data와 오류 상태를 확인하는 연결 키다. 정확한 API 계약은 Bruno와 Product Bible, 실행 여부는 소스 Controller를 기준으로 판단한다.
